01 · Uvod i radno okruženje

Radno okruženje

Pokretanje programa

Program je običan tekstualni fajl sa ekstenzijom .py. Pokrećemo ga iz terminala (na Windowsu: Command Prompt).

# pokretanje programa
$ python test.py
# interaktivni režim (shell)
$ python
# pokreni program, pa ostani u shell-u
$ python -i test.py

Editor

  • Tab emulacija: tab postaje 4 razmaka, jer Python razlikuje tabove i razmake
  • Isticanje sintakse pomaže da uočite greške
  • Nikako Word i slični programi: ubacuju formatiranje koje Python ne razume

Verzija i dokumentacija

Instalirajte Python 3. Potpun spisak mogućnosti je u zvaničnoj dokumentaciji: docs.python.org

Na Linuxu i macOS-u komanda je često python3 umesto python. Knjiga je pisana dok se prelazilo sa Pythona 2 na 3: svi primeri rade u obe verzije, ali u Pythonu 2 treba na početak programa dodati from __future__ import division (zbog celobrojnog deljenja). Knjiga savetuje početnicima jednostavan editor (Notepad++, gedit i sl.) umesto IDE okruženja, jer IDE na početku samo komplikuje stvari.
