02 · Štampanje i rad sa tekstom

Stringovi i brojevi su različiti tipovi

my_dna = "ATGCGAGT"
# len vraća broj (int), a ne string
dna_length = len(my_dna)
print("The length of the DNA sequence is " + dna_length)
# ispravno: str pretvara broj u string
print("The length of the DNA sequence is " + str(dna_length))

IZLAZ ČETVRTE LINIJE

TypeError: can only concatenate str (not "int") to str

Python ne zna kako da spoji string (str) i ceo broj (int).

Spajanje stringova: +

"AATT" + "GGCC" daje "AATTGGCC". Rezultat je opet string, pa spajanje može i unutar print.

len, kao i print, prima jedan argument, ali ništa ne ispisuje: vraća vrednost (povratnu vrednost) koju treba sačuvati ili iskoristiti. Formalno: str je funkcija koja prima jedan argument tipa broj i vraća vrednost tipa string koja ga predstavlja. Razumevanje tipova sprečava veliki deo frustracija početnika. U Pythonu 2 poruka glasi cannot concatenate 'str' and 'int' objects. Broj se može ispisati i direktno, print(dna_length), samo ne može da se spoji sa stringom bez str.
