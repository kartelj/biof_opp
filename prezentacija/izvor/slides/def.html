05 · Pisanje sopstvenih funkcija

Definisanje funkcije

def get_at_content(dna):
    length = len(dna)
    a_count = dna.count('A')
    t_count = dna.count('T')
    at_content = (a_count + t_count) / length
    return at_content

Pre pisanja odredite ulaz i izlaz: jedan argument tipa string (DNK), a povratna vrednost je broj.

Pisanje funkcije zove se definisanje. Ime funkcije i imena argumenata su proizvoljna, kao i imena promenljivih. Telo može imati koliko god linija, sve sa istim uvlačenjem; u telu argument koristimo preko imena iz prve linije. Povratna vrednost je preciznije tipa float, broj sa decimalnom tačkom. U Pythonu 2 je za deljenje potreban from __future__ import division.
