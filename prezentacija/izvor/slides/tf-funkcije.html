Funkcije koje vraćaju True ili False

Da li je sekvenca bogata sa AT?

def is_at_rich(dna):
    length = len(dna)
    a_count = dna.upper().count('A')
    t_count = dna.upper().count('T')
    at_content = (a_count + t_count) / length
    if at_content > 0.65:
        return True
    else:
        return False

Kraće: vrati sam uslov

True i False su obične ugrađene vrednosti: mogu se čuvati u promenljivama, prosleđivati i vraćati iz funkcija kao brojevi i stringovi. Zato funkcija koja uvek vraća True ili False može da se koristi kao uslov. Granica 0.65 za „bogata sa AT” je izbor iz knjige. Kraća verzija odmah vraća rezultat poređenja; na prvi pogled je neobična, ali je čitljivija kad se naviknete.
