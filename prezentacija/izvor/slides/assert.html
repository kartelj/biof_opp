Testiranje funkcija: assert

Ako uslov posle assert nije tačan, program staje sa AssertionError. Kao pozitivna kontrola u laboratoriji.

assert get_at_content("A") == 1
assert get_at_content("G") == 0
assert get_at_content("ATGC") == 0.5
assert get_at_content("AGG") == 0.33
assert get_at_content("AGG", 1) == 0.3
assert get_at_content("AGG", 5) == 0.33333
# nepoznate baze N ne bi smele da utiču
assert get_at_content("ATGCNNNNNNNNNN") == 0.5

def get_at_content(dna, sig_figs=2):
    # ispravka: izbaci N pre računanja
    dna = dna.replace('N', '')
    # … ostatak kao ranije

  • Pokazuju da li je greška u funkciji ili u kodu koji je poziva
  • Posle izmene funkcije ponovo pokrenite testove
  • Dokumentuju očekivani izlaz za dati ulaz
  • Proveravaju neobične ulaze, npr. baze N
Rešenja ranijih vežbi smo proveravali ispisom i poređenjem sa odgovorom koji znamo napamet. assert to radi automatski: posle reči assert ide poziv funkcije, dva znaka jednakosti i očekivani rezultat. Dva znaka = objašnjavamo u poglavlju 6. Test za sekvencu sa N u početku pada; kad dodamo uklanjanje N, prolazi. Ponovno pokretanje testova posle izmene u razvoju softvera zove se regresiono testovanje.
