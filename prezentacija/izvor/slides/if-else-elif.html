if, elif i else

# file1, file2, file3: otvoreni za pisanje
accs = ['ab56', 'bh84', 'hv76', 'ay93', 'ap97', 'bd72']
for accession in accs:
    if accession.startswith('a'):
        file1.write(accession + "\n")
    elif accession.startswith('b'):
        file2.write(accession + "\n")
    else:
        file3.write(accession + "\n")

if

blok se izvršava samo ako je uslov tačan

elif

nova grana bez novog nivoa uvlačenja

else

nema svoj uslov: izvršava se kad nijedna grana iznad nije

REZULTAT

one.txt:   ab56 ay93 ap97
two.txt:   bh84 bd72
three.txt: hv76

Obrazac je poznat: reč if, uslov, dvotačka i uvučeni blok. Kod unutar if u petlji uvučen je dvaput, jednom za petlju i jednom za if. Više od tri nivoa uvlačenja obično znači da deo koda treba izdvojiti u funkciju. Bez elif bismo pisali if unutar else, što dodaje po jedan nivo uvlačenja za svaku granu; sa elif možemo imati koliko god grana uz samo jedan dodatni nivo. if i else (i elif) stoje na istom nivou uvlačenja.
