04 · Liste i petlje

Liste: mnogo vrednosti u jednoj promenljivoj

0

"Homo sapiens"

-3

1

"Pan troglodytes"

-2

2

"Gorilla gorilla"

-1

Svaka stavka je element. Indeksi kreću od 0, a negativni broje od kraja: apes[-1] je poslednji element.

apes = ["Homo sapiens", "Pan troglodytes", "Gorilla gorilla"]
conserved_sites = [24, 56, 132]
print(apes[0])                                # Homo sapiens
chimp_index = apes.index("Pan troglodytes")   # 1
ranks = ["kingdom", "phylum", "class", "order", "family"]
lower_ranks = ranks[2:5]                      # ['class', 'order', 'family']

Listu pravimo uglastim zagradama, a elemente razdvajamo zarezima; elementi mogu biti stringovi, brojevi ili bilo koje druge vrednosti. Metod index radi obrnuto od indeksiranja: za poznat element daje njegov indeks. Isecanje [2:5] je ista notacija kao za podstringove u poglavlju 2, sa istim pravilom (početak uključen, kraj isključen). To nije slučajnost: kad smo isecali stringove, tretirali smo string kao listu karaktera.
