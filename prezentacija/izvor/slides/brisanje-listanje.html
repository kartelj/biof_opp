09 · Fajlovi, programi i korisnički unos

Provera, brisanje i listanje

if os.path.exists("/home/martin/email.txt"):
    print("You have mail!")
# fajl, prazan folder, folder sa sadržajem
os.remove("/home/martin/unwanted_file.txt")
os.rmdir("/home/martin/empty")
shutil.rmtree("/home/martin/full")
# sadržaj foldera; "." je trenutni folder
for file_name in os.listdir("/home/martin"):
    print("one file name is " + file_name)

os.path.exists vraća True ili False, pa ide direktno u if.

os.listdir vraća listu imena, pa kroz nju prolazimo petljom.

Brisanje je trajno: fajlovi ne idu u korpu za otpatke.

Za brisanje postoje tri funkcije, zavisno od toga šta brišemo: os.remove za jedan fajl, os.rmdir za prazan folder i shutil.rmtree za folder sa svim fajlovima u njemu. os.path.exists odgovara na pitanje iz poglavlja 3: kako da proverimo da li fajl postoji pre otvaranja. os.listdir prima putanju foldera kao string; za trenutni folder koristi se ".". Te funkcije pozivamo uz import os i import shutil sa prethodnog slajda.
