Tri grane: ugnežđeni if ili elif

if unutar else

for accession in accs:
    if accession.startswith('a'):
        file1.write(accession + "\n")
    else:
        if accession.startswith('b'):
            file2.write(accession + "\n")
        else:
            file3.write(accession + "\n")

Radi, ali je teško za čitanje: svaka nova grana dodaje još jedan nivo uvlačenja.

elif = else + if

for accession in accs:
    if accession.startswith('a'):
        file1.write(accession + "\n")
    elif accession.startswith('b'):
        file2.write(accession + "\n")
    else:
        file3.write(accession + "\n")
 

Koliko god grana, uvek samo jedan dodatni nivo uvlačenja.

Zadatak: tri fajla, za brojeve koji počinju sa a, za one koji počinju sa b i za sve ostale. Prvo rešenje stavlja drugi if unutar else prvog; radi, ali svaka dodatna grana traži novi nivo uvlačenja. elif spaja else i if, pa isti program ima samo dva nivoa uvlačenja. Na isti način možemo dodati grane za c, d, e i tako dalje, bez dodatnog uvlačenja. Fajlovi file1, file2 i file3 su otvoreni za pisanje pre petlje.
